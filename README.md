# Stock Market Performance & Trading Analytics Dashboard

An interactive **Power BI dashboard** for analyzing stock market performance, trading activity, price trends, and company-level insights.

## 📊 Overview

**Stock Market Performance & Trading Analytics Dashboard** is a business intelligence project developed using Microsoft Power BI to transform stock-market data into an interactive and easy-to-understand analytical dashboard.

The project focuses on exploring market performance, trading behavior, price movements, and company-level comparisons through dynamic visuals and interactive filters.

This project demonstrates practical skills in:

* Data Analysis
* Data Visualization
* Business Intelligence
* Power BI
* Power Query
* DAX
* Dashboard Design
* Data Storytelling

---

## 🎯 Objectives

* Analyze stock-market performance using interactive visualizations.
* Track stock price and trading activity trends.
* Compare performance across companies.
* Present important metrics through KPI-style visuals.
* Enable interactive exploration using slicers and filters.
* Build a professional Business Intelligence portfolio project.

## 📈 Dashboard

### Page 1 — Performance Overview

The first dashboard page provides an overview of stock-market performance with key metrics, trend analysis, and interactive filtering.

It is designed to help users quickly understand overall market performance and explore selected companies or periods.

### Page 2 — Trading Analytics

The second page provides a deeper analytical view of trading-related activity and company-level comparisons.

It complements the first page by allowing more detailed exploration of market behavior and performance.
