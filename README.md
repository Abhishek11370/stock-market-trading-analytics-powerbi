# Stock Market Performance & Trading Analytics Dashboard

An interactive **Power BI dashboard** designed to analyze stock market performance, trading activity, price trends, and company-level insights.

## 📊 Project Overview

The **Stock Market Performance & Trading Analytics Dashboard** transforms stock-market data into an interactive and visually driven analytical report.

The dashboard helps users explore:

* Stock price performance
* Trading activity
* Market trends over time
* Company-level comparisons
* KPI-based performance analysis
* Interactive filtering and exploration

The project demonstrates an end-to-end **Data Analytics and Business Intelligence workflow** using Microsoft Power BI.

---

## 🎯 Project Objectives

* Analyze stock-market performance through interactive visualizations.
* Identify trends in stock prices and trading activity.
* Compare performance across different companies.
* Provide an easy-to-use dashboard for exploring market data.
* Demonstrate practical skills in Power BI, Power Query, DAX, and data visualization.

## 📈 Dashboard Pages

### Page 1 — Performance Overview

The first page provides a high-level view of stock-market performance using KPI cards, trend analysis, and interactive filtering.

It is designed to help users quickly understand overall performance and explore selected companies or periods.

### Page 2 — Trading Analytics

The second page provides a deeper analytical view of trading activity and company-level comparisons.

It complements the overview page by allowing more focused exploration of market behavior and trading-related information.
